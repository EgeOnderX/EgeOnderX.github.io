🧠 N-Gram AI (DumbGpt)

A lightweight, 100% offline language model running on a dynamic 2D–5D N-gram transition architecture.

📰 Project Highlights

  • Dynamic N-Gram Engine: Uses 2D to 5D token context windows to predict natural word transitions without cloud APIs.
  • Context Fallback Strategy: Evaluates context from highest (5D) to lowest (2D) tier to maintain maximum sentence coherence.
  • Self-Training Memory: Learns new vocabulary and n-gram associations directly from conversation inputs in real time.
